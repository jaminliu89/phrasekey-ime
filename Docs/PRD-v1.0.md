# PhraseKey PRD

> 文档版本：v2.0
> 日期：2026年08月24日
> 对应版本：iOS v0.1-alpha
> 状态：执行基线

## 一、版本目标

交付一款能在 iPhone 真机稳定使用的实验性中文输入工具，并完成“新增快捷短语→立即召回→跨设备同步”的核心闭环。页面数、代码量和单纯构建成功不算完成。

## 二、P0 用户故事

### US-01 稳定使用中文输入

作为用户，我希望 PhraseKey 在常用 App 中正常输入中文。

验收：键盘可安装、启用、切换和再次唤起；字母、候选、删除、空格、回车、数字、符号及中英文切换可用；锁屏和前后台切换后仍可用。

### US-02 浏览并插入快捷短语

作为用户，我希望点击顶部“短语”就能看到已保存内容。

alpha 验收：提供快捷短语列表、剪贴板入口和删除；点击立即上屏。置顶、分组、长按菜单属于后续迭代，不能写成当前已交付。

### US-03 在键盘内新增

作为用户，我希望复制一段以后可能会用的文字后，直接点 `＋` 保存到输入法备用。

alpha 验收：点击 `＋` 后才读取剪贴板并自动带入键盘内的确认编辑器；用户可取消或保存，系统自动建议并避让快捷码；保存后不离开当前 App。复杂手动编辑与快捷码修改由 Host App 完成。最近上屏内容仅作为用户可主动开启的候选来源，首版不默认记录。

### US-04 通过短语按键召回

作为熟练用户，我希望输入少量字符召回完整文字。

验收：系统建议2至4位按键；冲突时提示并给备选；精确命中进入候选第一位；模糊命中不破坏正常中文候选。

### US-05 Host App 管理

验收：新增、编辑、删除、搜索；默认按保存时间倒序；一键导出完整短语库为 `.xlsx`（Excel／WPS／Numbers 可打开），字段为短语内容、快捷码、保存时间；显示同步状态和失败原因；提供键盘启用、Full Access与隐私说明。

### US-06 Apple 多端同步

验收：Host App 使用 CloudKit 私有库；Keyboard Extension 使用 App Group 本地数据；增删改和软删除有合并规则；断网和同步错误不阻塞键盘。

## 三、核心界面

```text
默认态
┌──────────────────────────────────┐
│        [短语]                         │
├──────────────────────────────────┤
│ 1 我们   2 我是   3 我们的         │
├──────────────────────────────────┤
│            中文实验键盘            │
└──────────────────────────────────┘

短语态
┌──────────────────────────────────┐
│ 收起 │ 剪贴板 / 快捷短语 │ ＋      │
├──────────────────────────────────┤
│ 您好，方案已经整理好了……         │
│ 收到，我马上处理。                │
└──────────────────────────────────┘
```

快捷短语不再占据底部空格键附近布局。默认展示最近保存；点击一次上屏；空状态直接提供新增。搜索、导入、置顶和分组以 Host App 为主。

## 四、数据契约

```swift
struct QuickPhrase: Codable, Identifiable {
    let id: UUID
    var text: String
    var shortcut: String?
    var groupId: UUID?
    var isPinned: Bool
    var useCount: Int
    var createdAt: Date
    var updatedAt: Date
    var lastUsedAt: Date?
    var deletedAt: Date?
}
```

旧 `Hotword` 数据必须显式迁移，不得删除用户数据。

## 五、隐私与权限

- 不建立完整输入历史数据库；快捷短语功能不从 `documentContextBeforeInput` 自动抽取或保存文本。
- 默认不记录最近上屏内容；若后续提供该选项，只使用当前会话内存缓冲并由用户主动开启。
- 密码、验证码和安全文本不缓存。
- 剪贴板只在用户主动点击 `＋` 或“剪贴板”页签时读取，不后台轮询、不自动入库。
- CloudKit 使用用户私有数据库。
- Full Access 只用于 App Group 写入和快捷短语同步，不把击键上传到开发者服务器。
- Full Access 关闭时，基础输入和只读本地短语应继续工作。

## 六、非功能需求

- 键盘首帧优先于完整词库加载，不能持续白屏。
- 快捷短语查询不访问网络。
- App Group、CloudKit和词库异常均需优雅降级。
- 性能与内存指标以目标真机实测锁定，不沿用未经验证的旧数字。
- 覆盖无数据、加载、成功、失败、无权限和离线状态。

## 七、发布门禁

- 干净 `xcodebuild` 输出。
- Simulator 冒烟结果；若基础二进制缺少 Simulator slice，必须如实记录并改由真机 UI 证据补足，不能伪报通过。
- 真机三 App 输入记录。
- 新增、召回、编辑和删除完整证据。
- 双设备同步、断网和冲突测试。
- 30分钟稳定性测试的设备、系统版本和结果。
- 未验证能力不得写成“已完成”。

## 八、版本范围

v0.1-alpha：iOS 实验性中文输入、顶部工具栏、快捷短语本地闭环、Host App、App Group、iPhone/iPad CloudKit同步、导入导出和隐私引导。

v0.2：macOS接入同一模型与同步；评估模板变量和剪贴板历史。

范围外：附加编码方案、AI、语音、翻译、表情、皮肤、团队共享、Windows、Android和自动采集完整输入历史。
