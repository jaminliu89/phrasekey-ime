# 字典与音形码表导入指南

PhraseKey 的数据层全部开放格式，你可以自由导入自定义字典和小鹤音形码表。所有文件都放在**数据目录**下：

- **macOS**：`~/Library/Application Support/PhraseKey/`
- **iOS**：App Group 容器 `group.com.phrasekey.ime`（宿主 App 可查看/管理）
- **自定义**：在 `config.json` 里设 `dataDir` 指向任意目录（iCloud Drive / 云盘 / git 仓库）

---

## 文件清单

| 文件名 | 格式 | 用途 | 自动加载 |
|---|---|---|---|
| `hotwords.json` | JSON 数组 | 常用语 / 短语（你的个人快捷语） | ✅ |
| `user_dict.tsv` | TSV | 手动维护的外部词库 | ✅ |
| `learned_dict.tsv` | TSV | 自学习词典（系统自动生成，不要手动改） | ✅ |
| `xingma.tsv` | TSV | 小鹤音形形码表（单字 → 形码） | ✅ |
| `config.json` | JSON | 设置（输入方案 / 数据目录 / 剪贴板历史开关） | ✅ |

---

## 1. 常用语（hotwords.json）

### 格式

```json
[
  { "hw_id": "1690000000000", "text": "今天天气不错", "key": "jttq" },
  { "hw_id": "1690000000001", "text": "柳俊明", "key": "ljm" }
]
```

字段说明：
- `hw_id`：唯一 ID（毫秒时间戳即可），用于去重
- `text`：完整内容
- `key`：简码（可选），打 key 直接置顶候选

### 使用方式

**方式一：打简码（最快）**
输入你设置的 key，常用语直接出现在候选条最前面（带 ⌘ 标记），按数字或空格上屏。
长文本会在候选条中截断显示，点上去就插入完整内容。

**方式二：浏览式（不记 key）**
- **macOS**：菜单栏输入法图标 →「常用语…」→ 打开面板 → 搜索/浏览 → 双击或回车插入
- **iOS**：打开 PhraseKey 宿主 App → 常用语列表 → 点击编辑

**方式三：一键收藏（最高频）**
- **macOS**：复制一段文字 → 菜单栏输入法图标 →「从剪贴板添加常用语」→ 自动生成简码
- **iOS**：复制 → 打开 PhraseKey App → 右上角 + →「从剪贴板粘贴」

### 导入

**方法一：macOS 菜单导入**
1. 点击菜单栏 PhraseKey 图标 →「导入常用语…」
2. 选择 CSV 或 JSON 文件
3. 自动去重后导入

**方法二：直接放数据目录**
把 `hotwords.json` 扔进数据目录，输入法重启后自动加载。

**方法三：从其他输入法迁移**
- 微信输入法：导出常用语 → CSV 格式 → PhraseKey 直接导入
- 搜狗输入法：导出 → 转成 CSV/JSON → 导入
- 任何含「简码 + 内容」两列的 CSV 都能识别

## 2. 用户词典（user_dict.tsv）

手动维护的外部词库，适合批量导入专业领域词汇、人名地名等。

### 格式

```
pinyin	word	frequency
ni hao	你好	100
zai jian	再见	50
```

- 列分隔：Tab（TSV）
- 拼音：空格分隔音节，无声调，ü 用 v 代替
- 词频：整数，越高排越靠前（可选，默认 0）

### 导入方式

把文件命名为 `user_dict.tsv` 放到数据目录即可，输入法启动时自动加载。

> **与自学习词典的区别**：
> - `user_dict.tsv` = 你手动维护的词库（专业词、人名等），不会被自动修改
> - `learned_dict.tsv` = 系统自动学习的词（你选过的词自动记录），每次选词频次 +1
> - 两者同时生效，排序上用户词典 + 自学习词典都在**内置词典前面**

## 3. 自学习词典（learned_dict.tsv）

系统自动维护，**不需要手动操作**。

### 工作原理

每次你从候选列表里选了一个词（空格/数字键上屏），如果这个词来自词库（不是常用语），系统会：

1. 把它记入 `learned_dict.tsv`（新词 freq=1）
2. 已存在的词，freq +1
3. 下次同样的拼音输入，学过的词排在更前面

### 学习效果

- 经常打的词越来越靠前，越用越顺手
- 学习数据跟随数据目录同步（iCloud / git 都行），换设备不用重新学
- 3 秒 debounce 写盘，不会频繁读写磁盘

### 清空学习记录

直接删除数据目录下的 `learned_dict.tsv`，输入法重启后从零开始。

## 4. 小鹤音形码表（xingma.tsv）

小鹤音形 = 小鹤双拼 + 形码辅助。形码表是单字到形码的映射，安装后输入时可以追加形码缩小候选范围。

### 格式

```
char	code
的	r
一	y
是	o
在	s
了	d
```

- 列分隔：Tab（TSV）
- 第一列：单字
- 第二列：形码（小鹤音形编码，1~2 个字母）

### 安装方式

把形码表命名为 `xingma.tsv` 放到数据目录，输入法重启后自动加载。

未安装码表时，音形模式退化为纯双拼（不影响使用）。

### 小鹤音形输入规则

输入 = 双拼编码 + 形码后缀。形码位数 = 字数 × 每字形码数（通常 1 位）。

例：「你好」
- 纯双拼：`nihc`
- 音形（两字加形）：`nihcr`（r = 你 的形码 + 好 的形码首字母，具体看码表）

系统会自动尝试把末 1~2 个按键当作形码，匹配成功就过滤候选，匹配不上就退化为双拼。

## 5. 配置文件（config.json）

```json
{
  "scheme": "flypy",
  "dataDir": "",
  "clipboardHistory": false
}
```

字段：
- `scheme`：输入方案，`pinyin`（全拼）/ `flypy`（小鹤双拼）/ `flypyXing`（小鹤音形）
- `dataDir`：自定义数据目录路径（支持 `~`），空 = 默认目录
- `clipboardHistory`：剪贴板历史（预留字段）

macOS 上可通过菜单栏「PhraseKey Settings…」图形化修改。

## 6. 跨设备同步

因为所有数据都是纯文本开放格式，同步方式任选：

### iCloud Drive（推荐）
1. 在数据目录里建一个指向 iCloud 的 symlink，或者直接把 `dataDir` 设为 iCloud 路径：
   ```json
   { "dataDir": "~/Library/Mobile Documents/com~apple~CloudDocs/PhraseKey" }
   ```
2. Mac 和 iPhone 上都用同一个 iCloud 账号

### Git
1. 数据目录 `git init`，推到私有仓库
2. 各设备 `git pull` / `git push`

### 其他云盘
Dropbox、OneDrive、坚果云等，把数据目录放进同步文件夹即可。

## 7. 常见问题

**Q: 导入后看不到词？**
A: 检查文件编码是不是 UTF-8。Windows 导出的 CSV 可能是 GBK，用文本编辑器转成 UTF-8 再导。

**Q: 自学习不生效？**
A: 确认你选的是词库候选（没有 ⌘ 标记的）。常用语候选不参与自学习——常用语本身就是你手动加的。

**Q: 形码表哪里找？**
A: 小鹤音形官方码表可从小鹤输入法官网下载，转成 TSV 格式（单字 + Tab + 编码）即可。也可以在社区找现成的 xingma.tsv 文件。

**Q: iOS 上怎么放文件？**
A: 通过宿主 App（PhraseKey）导入，或者用 iTunes 文件共享 / 访达 → 手机 → 文件 → PhraseKey。
