# PhraseKey 产品定义

> 版本：v2.0
> 日期：2026年08月24日
> 状态：当前唯一产品定义
> 首发平台：iOS；macOS 在 iOS 核心闭环验收后接入

## 一、一句话定位

**PhraseKey 是一款内置快捷短语本、面向 Apple 多端的实验性中文输入工具。**

它首先是一款可以日常使用的中文输入法，同时把用户反复输入的句子、回复、地址、模板和长文本保存为快捷短语。用户既可以打开短语面板点选，也可以输入短语按键，从候选栏直接召回整段文字。

## 二、核心问题与用户

系统自定义短语入口深、长文本管理弱；微信和搜狗的常用语封闭；专门的短语键盘又不是完整中文输入法。PhraseKey 将两件事合并：**实验性中文输入，同时随时保存和复用快捷短语。**

核心用户是高频中文输入者，以及内容创作者、客服、电商、销售和需要反复回复的人。典型内容包括客户回复、项目说明、地址、社群通知、视频简介及任何“以后可能还会用到”的文字。

## 三、核心闭环

```text
正常输入：唤起 PhraseKey → 输入编码 → 候选 → 上屏

保存短语：用户先复制值得复用的文字 → 顶部“＋”
         → 自动带入剪贴板预览
         → 系统建议短语按键 → 用户确认 → 保存

再次使用：打开“短语”浏览和搜索 → 点选上屏
       或输入短语按键 → 候选第一位 → 上屏

多端同步：本地立即可用 → Host App 同步 CloudKit
       → iPhone / iPad / Mac 获得相同数据
```

断网和同步失败不能影响输入与本地短语使用。

## 四、产品形态

### iOS Keyboard Extension

- 中文输入和候选。
- 顶部工具栏：短语、添加、剪贴板、更多。
- 最近、置顶、分组和搜索。
- 点击短语直接上屏，精确短语按键进入候选第一位。
- 键盘内快速确认新增；复杂编辑进入 Host App，离线读取本地数据。

键盘不负责复杂同步和冲突处理，也不能依赖网络才能工作。

### iOS Host App

- 首次安装、键盘启用和 Full Access 引导。
- 新增、编辑、删除、搜索、分组、置顶和排序。
- 导入、导出、备份与恢复。
- CloudKit 同步、状态显示和冲突处理。

### macOS

第二阶段复用相同数据模型和 CloudKit Container，提供中文输入、短语召回和完整管理。

## 五、快捷短语模型

| 字段 | 含义 |
|---|---|
| `id` | 跨设备稳定 UUID |
| `text` | 多行正文 |
| `shortcut` | 可选短语按键 |
| `groupId` | 可选分组 |
| `isPinned` | 是否置顶 |
| `useCount` | 使用次数 |
| `createdAt` / `updatedAt` | 创建和修改时间 |
| `lastUsedAt` | 最后使用时间 |
| `deletedAt` | 软删除时间，用于同步 |

标题、来源、AI标签和复杂版本历史不进入首版。

## 六、召回与排序

用户可以通过精确短语按键、文本或拼音搜索、最近/置顶/分组三种方式召回。

```text
短语按键精确命中
→ 置顶的精确短语
→ 正常中文候选
→ 短语按键前缀命中
→ 短语正文模糊命中
```

只有精确短语按键稳定占据第一候选。系统建议2至4位按键并检查冲突，用户可以修改或留空，不能生成不可记忆的全句首字母串。

## 七、产品原则

1. 输入稳定高于功能数量。
2. 快捷短语是一等公民，入口在键盘顶部可见。
3. 本地优先，网络不阻塞输入。
4. 用户主动保存，不自动采集完整输入历史。
5. 剪贴板是新增短语的默认来源，但只在用户点击“＋”后读取；最近上屏仅为可选能力。
6. 不记按键也能浏览和搜索，熟练后再用编码召回。
7. Apple 生态先行，使用 CloudKit 私有数据库同步。

## 八、v0.1-alpha 范围

必须具备：

- iOS 真机稳定的实验性中文键盘。
- 顶部工具栏与快捷短语面板。
- 最近、置顶、分组、搜索和键盘内新增。
- 自动建议短语按键与精确召回。
- Host App 完整管理、App Group 本地共享。
- iPhone/iPad CloudKit 同步，离线可用。
- 导入、导出、隐私和权限说明。

明确不做：附加编码方案、AI、自动采集输入历史、图片、文件、语音、翻译、表情、皮肤、团队共享、Windows和Android。

## 九、完成定义

1. 真机能在微信、备忘录和 Safari 中稳定唤起。
2. 连续输入常见中文无断档。
3. 键盘内新增多行短语后立即可见。
4. 输入短语按键时目标短语进入候选第一位并可上屏。
5. 最近、置顶、分组和搜索均可找到短语。
6. 重启、锁屏、切换 App 后数据不丢失。
7. 断网时仍可输入和使用本地短语。
8. 两台设备新增、修改和删除同步，不静默覆盖。
9. 真机连续输入30分钟不崩溃、不白屏、不丢键。

## 十、当前事实状态

截至2026年08月24日：中文输入 Engine 探针通过；iOS 已迁移到 HamsterKeyboardKit 底座，完成可见“短语”按钮、剪贴板/快捷短语工作区、主动 `＋` 预览确认、自动快捷码、点击上屏及 Host App 搜索/新增/编辑/删除。短语管理默认按保存时间倒序，支持一键导出完整库为 `.xlsx`（Excel／WPS／Numbers 可打开）；真机签名构建、安装与启动成功。App Group 的同文件读写、键盘端完整点击及 `.xlsx` 实机打开仍需实体机 UI 证据；CloudKit 未实现；遗留 Rime 链接导致 Simulator 缺少架构，但不阻塞真机包。
