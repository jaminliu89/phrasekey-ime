## 一、一句话定位

**为内容创作者打造的、以"个人词库"为核心的开源输入法。**

不是又一个搜狗/百度的复刻。不是"又快又准的输入法"。
是**把你的写作记忆、常用句式、专属名词，从大脑里搬出来，在任何地方一键调用**的输入法。

---

## 二、为什么做这个（背景与痛点）

### 2.1 用户画像（核心人群）

**主用户：内容创作者**——写文案的、做视频的、开公司的、程序员写文档的。
每天打字 4 小时以上，有大量重复输入的内容：
- 固定句式 / 回复模板
- 人名地名产品名（团队成员、客户、项目名）
- 常用短语（"好的没问题"、"收到，我看一下"）
- 长文本（地址、邮箱、收款码话术）

**次用户：双拼 / 音形用户**——对打字效率有洁癖的人。
用全拼觉得慢、用搜狗觉得脏、用鼠须管觉得配置门槛高。

### 2.2 核心痛点链

| 层级 | 痛点 | 现有方案的问题 |
|------|------|----------------|
| L1 表面 | 常用语到处存，用的时候找不到 | 微信输入法只能在微信里用、备忘录要切出去、TextExpander 太贵 |
| L2 体验 | 输入法候选词不准，总在选 | 商业输入法靠大数据猜，不懂你的个人语境 |
| L3 深层 | 打字速度跟不上思考速度 | 全拼太慢、双拼学习曲线陡、形码更陡 |
| L4 本质 | 你的文字资产被锁在各家输入法里 | 搜狗导出格式不公开、微信输入法只能导 CSV、换设备全没了 |
| L5 终极 | 你越打字越熟练，但输入法越用越笨 | 商业输入法的"智能"是广告智能，不是你个人的智能 |

### 2.3 我们的判断

**输入法的下一个战场不是"更准的拼音"，是"更懂你的词库"。**

拼音准确率已经摸到天花板了（全拼 99%+），再提升 0.1% 用户感知不到。
真正的效率差在**个人词汇量**——你脑子里有多少词是输入法候选栏里没有的。
谁先把"个人词库"做透，谁就切走高端用户。

## 三、竞品分析与我们的位置

### 3.1 竞品全景（六款产品拆解）

| 产品 | 核心优势 | 致命短板 | 我们能抄什么 | 我们怎么差异化 |
|------|----------|----------|--------------|----------------|
| **小鹤音形** | 双拼+形码天花板，老用户盲打效率极高 | 闭源码表、无 Mac 原生客户端、UI 丑、无常用语 | 双拼键位规范、形码过滤逻辑 | 开源 + 原生 + 常用语优先 + 现代 UI |
| **同文输入法（Android）** | 开源、高度可定制、Rime 生态 | 只有 Android、配置门槛极高、普通用户劝退 | Rime 词库格式兼容、方案切换架构 | 降低门槛、开箱即用、Mac/iOS 原生 |
| **鼠须管（Squirrel / Rime）** | Mac 上开源标杆、极度可定制 | 配置要写 YAML、UI 极丑、零引导、新人 3 天才能上手 | 方案架构思想、词库生态 | 可视化配置、零配置开箱、现代 UI |
| **Google 输入法（Gboard）** | UI 干净、双拼方案全、流畅 | 无常用语管理、无个人词库同步（墙内）、隐私担忧 | 候选栏视觉规范、动效、键盘布局 | 加上个人词库核心 + 国内可用 |
| **微信输入法** | 常用语功能好用、微信生态打通 | 只有 iOS/Android、无 Mac、封闭生态、数据在微信手里 | 常用语面板交互、快捷短语触发 | 跨平台 + 数据自管 + 开源 |
| **搜狗输入法** | 词库最全、皮肤最多、功能最杂 | 广告多、隐私差、臃肿、越来越卡 | 候选排序算法、用户词自学习 | 减法 + 开源 + 无广告 + 个人数据优先 |

### 3.2 我们的差异化定位

**横轴**：从"通用打字工具"到"个人文字资产平台"
**纵轴**：从"闭源商业"到"开源透明"

我们的位置：**右上角——开源的个人文字资产平台**

```
        闭源商业 │                  │  开源透明
                │                  │
  通用打字工具   │  搜狗 百度 QQ    │  鼠须管 同文
                │                  │
        ────────┼──────────────────┼────────
                │                  │
  个人文字资产   │  微信输入法      │  ★ PhraseKey
                │  TextExpander    │
                │                  │
```

**核心差异（一句话说清我们和别人不一样在哪）**：

- 和搜狗比：我们没有广告，你的数据是你的
- 和鼠须管比：我们开箱就能用，不用写三天配置
- 和微信输入法比：我们跨平台，数据不在腾讯手里
- 和小鹤比：我们是开源的，有 Mac 版，常用语是一等公民
- 和 TextExpander 比：我们是完整输入法，不是外挂工具

## 四、产品原则（铁律）

### 原则 1：常用语 > 词库 > 拼音准确性

资源分配优先级：个人词库体验 > 通用词库覆盖 > 拼音引擎精度。
拼音 95 分和 98 分用户感知不到，但"我存的常用语能不能一秒调出来"是生死线。

### 原则 2：数据是用户的，不是我们的

- 所有数据格式公开（JSON/TSV）
- 数据目录用户可指定（本地 / iCloud / Git / 任意网盘）
- 不联网、不上传、不统计
- 用户随时可以导出、随时可以走

### 原则 3：开箱即用，但也可深度定制

默认配置就能让一个普通用户立刻用好（不用教、不用配）。
但高级用户可以深入改每一个细节（码表、方案、排序、UI）。
**不是"要么极简要么极客"的二选一，是渐进式暴露。**

### 原则 4：视觉要克制

- 对标 Gboard / 系统输入法的干净程度
- 不搞皮肤、不搞动画、不搞表情
- 颜色只用字重区分，不用花哨配色
- 候选栏是工具不是玩具

## 五、产品愿景与终局

### 5.1 终局形态

**PhraseKey = 你的文字外脑**

你所有反复输入的东西——常用语、模板、代码片段、回复话术、地址邮箱——都在 PhraseKey 里。
你打字的时候它自动出现在候选栏最前面，你不用想、不用找、不用切应用。

不止是输入法。它是**个人文本片段的运行时**。

### 5.2 三年路线（大方向，不是承诺）

| 阶段 | 时间 | 核心目标 | 关键标志 |
|------|------|----------|----------|
| v0.x | 现在→3个月 | 输入法本身好用 | 双拼+常用语+自学习全通，Mac/iOS 双端稳定 |
| v1.0 | 3→6个月 | 个人词库体系成型 | 词库管理工具、多设备同步、导入导出生态 |
| v2.0 | 6→12个月 | 从工具到平台 | 插件体系、第三方码表、脚本扩展、开发者 API |
| v3.0 | 1~2年 | 文字外脑 | AI 辅助补全、上下文感知、跨应用文本片段管理 |

### 5.3 明确不做的事（边界）

- 不做广告、不做内容推荐
- 不做云同步服务（用户自己选同步方式）
- 不做输入法皮肤商城
- 不做表情 / 贴纸 / GIF
- 不做 Windows / Linux 端（社区做，我们不主导）
- 不做语音输入
- 不做 OCR / 扫描输入

## 六、核心价值主张

### 对用户说的话

> "你每天反复打的那些字，不应该再打第二遍。"

### 三个核心价值

1. **更快**——你的专属词汇永远在候选第一位，不用翻页找
2. **更私**——数据在你自己的设备和云盘里，没有任何人看得到
3. **更自由**——开源格式，随时导出，永远不被锁在一家公司

---

## 七、商业模式（暂时不做，但要有方向）

- **核心功能永久免费开源**（MIT 协议）
- 未来可能的收入：
  - 云同步服务（可选付费，用户自建也行）
  - 企业版 / 团队版（团队共享词库、管理员管控）
  - 高级模板库（行业常用语包，按领域收费）
- **底线**：不靠广告、不靠卖数据、不靠捆绑安装

---

## 八、命名与品牌

- **产品名**：PhraseKey
- **Slogan**：Your phrases, everywhere.
- **中文名**：暂不强制，内部叫"短语键"也行
- **Logo**：字母 P + 钥匙（key）的结合，极简线条
- **品牌调性**：安静、可靠、专业、不打扰

## 附录：产品判断的底层假设

这些是我们做决策的前提，如果被证伪，产品方向要调整：

1. **假设**：有足够多的人在乎"打字效率"和"数据隐私"，愿意为了它们换输入法
   - **证伪信号**：月活用户 3 个月内低于 1000
2. **假设**：常用语 / 个人词库是比"拼音更准"更大的痛点
   - **证伪信号**：用户调研中，抱怨"候选不准"的人数远多于"常用语不好用"
3. **假设**：开源 + 跨平台 + 数据自管，可以从商业输入法手中抢走高端用户
   - **证伪信号**：用户增长主要来自"免费"而非"开源/隐私"
